# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately**, not through public GitHub issues.

- Prefer **[GitHub Security Advisories](https://github.com/g2rain/g2rain/security/advisories/new)** on the main organization repository if you have access.
- Alternatively, contact the maintainers at **g2rain_developer@163.com** with subject line containing `[SECURITY][g2rain-agent-app]`.

Include: affected version, reproduction steps, and impact if known. We will acknowledge receipt and coordinate a fix and disclosure timeline.

## Scope

This policy applies to the **g2rain-agent-app** repository (the Vue 3 + Vite + qiankun digital-workforce console micro-frontend application). Issues in the **create-g2rain-app** / **g2rain-app-cli** tool or in generated projects may be reported through the same channel; please state which component is affected.
